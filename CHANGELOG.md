# Changes

## 0.2.0 — 2026-10-08

- Reused installed agent-browser or Playwright, with one build-and-verify entry point and explicit failures instead of backend retries.
- Shared batched browser checks across engines; checked states, visible particles and real motion in every phase while saving only representative/mobile PNGs by default.
- Added a hub-feedback layout and regression tests for invisible arrows, hidden/frozen packets and isolated browser configuration.
- Added pinned optional browser dependencies, isolated-environment instructions and installed Linux/macOS browser discovery.
- Coalesced resize handling; rebuilt licensed examples and verified Playwright/GIF with existing Chrome on Linux. Mac runtime validation remains pending.

## 0.1.1 — 2026-10-08

- Added the MIT license at repository and portable-skill level, with copyright attributed to Albus-Hedwig.
- Added license scope and reference attribution notes, plus skill license metadata.
- Preserved the full MIT notice inside the template and generated standalone HTML examples.

## 0.1.0 — 2026-10-08

- Added the discoverable `animate-architecture` skill for terminal-style dynamic architecture diagrams.
- Added a data-driven offline HTML/SVG player with timeline playback, node state updates, directed flow, seeking, speed and viewport controls.
- Added a standard-library builder with route and schema validation, and an isolated browser verifier with optional GIF export.
- Added Agent collaboration and order-processing examples to validate different topologies.
- Added a local installer with backup and a repository workflow for iteration.
